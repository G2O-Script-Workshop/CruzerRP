# CruzerRP
It's a port from an infamous CruzerRP gamemode used by many on Gothic Multiplayer: Accrescere.
The original can be found here: https://github.com/GMP-Script-Workshop/CruzerRP

# Features
- Distance chat based on prefixes
- Basic ACP on commands
- Player Visual change (using commands)
- Classes

## Installation

1. Install project to your directory.
2. Register it in your `.xml` script list:
   ```xml
   <script src="Client.nut" type="client" />
   <script src="Server.nut" type="server" />
   ```
3. Create `database` folder in main server directory.
4. Start the server and have fun.
